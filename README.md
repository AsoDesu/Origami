# 🦋 Origami
An experimental Kotlin-based game engine and series of utilities for creating games & experiences in Minecraft!

At it's core, Origami is an **Entity Component System** based game engine, for clean,
small, reusable components, called **Behaviours**.

This is the second iteration of creating such a game engine, and is very bad, achieving all the
goals of Origami is a little difficult, this is already rewrite #2, and #3 already in progress.
